# 示例交接

## 用户意图与范围
教学目标是演示个人离线任务的新增、列表、完成及重启持久化，对应 AC-001–008。不含云同步、多人权限和 UI，也不代表真实用户已确认该需求。

## 改动与设计理由
task_store.py 封装 SQLite 与事务，cli.py 负责参数和输出，tests/test_tasks.py 验证契约及用户路径。选择标准库便于复现；选择真实数据库测试避免 mock 掩盖持久化问题。完成操作影响列表与旧数据，TC-006保护既有行。

## 验证与本地复跑
接手者按 README 运行 unittest 和编译，再跑独立演示库的 Quickstart。实际证据写在本地 .sop/evidence，不能把仓库示例的文字当作当前机器验证。需求/设计/验收仍待真实复核；性能、磁盘故障和并发未验证。

## 恢复与下一步
本例不修改外部系统。出错时先保留日志及演示库，不删除个人数据。代码可恢复到已知版本；若涉及库结构变更，先备份并设计兼容迁移。下一步由使用者完成场景验收、补实际证据，决定是否扩展 UI 或多用户需求。
