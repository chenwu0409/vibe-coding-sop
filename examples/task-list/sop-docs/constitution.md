# 任务清单示例宪法

## 项目定义
个人用户在本机新增、查看和完成任务，重启后继续使用。负责人角色为运行示例的使用者；本材料是教学规格，没有真实用户签字。

## 约束与理由
| ID | 规则 | 理由 | 验证 |
|---|---|---|---|
| C-001 | MUST 使用 Python 3.10+ 标准库与本地 SQLite | 演示包无外部服务依赖 | 检查导入，真实临时数据库测试 |
| C-002 | MUST 从 CLI 访问，并输出 JSON | 跨平台、可脚本验证 | 独立进程端到端测试 |
| C-003 | 测试 MUST 使用临时库 | 隔离用户数据 | setUp 创建独立临时目录 |
| C-004 | MUST 保留已有任务 ID、标题和状态 | 升级/重启不能丢任务 | 重开数据库、旧行回归 |

## 不做什么
不做账号/多人协作、云同步、提醒、删除和编辑任务；聚焦一个本地持久化闭环。

## 协作边界
在这个教学规格内可实现、测试与修改示例文件；变更共享数据规则或加入联网能力须重新确认需求。运行者决定使用/分发方式；本例不部署服务、不操作生产数据。

## 修订与例外
v1 示例决定：用 SQLite 而非纯内存，验证重启持久化；用 CLI 而非 UI，缩小验证面。无豁免。这里的技术选择仅对本示例成立。
